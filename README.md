# ClaimKaro 🏥

AI-powered insurance bill auditor for India. Detects overcharges in hospital bills and generates IRDAI-cited dispute emails.

## Live Demo
https://claimkaro-427022138660.asia-south1.run.app

## Tech Stack
- Gemini 3.5 Flash (multimodal bill extraction + dispute email generation)
- Google Cloud Run (deployment)
- FastAPI + Python

## Features
- Upload any hospital bill (JPG, PNG, PDF)
- Detects room rent cap violations, non-medical consumables, admin charges
- Cites specific IRDAI regulations for each violation
- Auto-generates legally-grounded dispute email
